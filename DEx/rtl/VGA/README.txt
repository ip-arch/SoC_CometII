[はじめに]

このディレクトリのファイル群は、
アルテラ社のFPGAボードDE2-70用に開発された、
テキストVRAM方式（横80文字、縦30行）のVGAコントローラです。
自由に使用、改変および再配布を行って構いません。
ただし、使用等に際して生じたいかなる損害に対しても、
原作者（西村克信 <knish@tokai.ac.jp>）は、
その責任を一切負わないものとします。


[ファイル]

README.txt		このファイル
VGA_ctrl.inc		VGAコントローラの宣言部
VGA_ctrl.nsl		VGAコントローラの記述部
RAM2P_16x4K.v		テキストVRAM用メモリ (*1)
VRAM.mif		テキストVRAMの初期値
VRAM-gen.pl		テキストVRAMの初期値作成スクリプト
ROM_8x4K.v		キャラクタジェネレータ用メモリ (*1)
CGROM.mif		キャラクタジェネレータ用データ
bdf2mif.pl		キャラクタジェネレータ用データ作成スクリプト
8x16rk.bdf		キャラクタジェネレータの元データ（X11R7より抜粋）

(*1) メモリ記述は Quartus II / MegaWizard で作成


[アドレスマップ]

番地		ビット	初期値	内容
------------	------	------	--------------------------------
0x000～0xFFB	15～12	15	テキスト色 (*3)
(*2)		11～ 8	0	テキスト背景色 (*3)
		 7～ 0	0x00	テキストデータ (ASCIIコード)
0xFEC		15～ 0	なし	クリア用データ (*4)
0xFED		 4～ 0	0	スクロール位置 (*5)
0xFEE		11～ 7	0	カーソル位置/縦方向 (*6)
		 6～ 0	0	カーソル位置/横方向 (*6)
0xFEF		11～ 8	0b0011	カーソル形状 (*6)
		 7～ 4	15	カーソル色 (*3)
		 3～ 0	0	カーソル背景色 (*3)
0xFF0～0xFFF	11～ 8	別表	パレット/赤
		 7～ 4		パレット/緑
		 3～ 0		パレット/青

(*2) 番地の上位5ビットが縦(0～31)、下位7ビットが横(0～127)に相当する
(*3) 色および背景色は、下記のパレット番号で指定する
(*4) テキスト領域(0x000～0xFFB)を書き込んだ値で初期化する
     初期化中はBUSYフラグとして読み出し可能
(*5) VRAMアドレスの上位5ビットに加算される
(*6) カーソルを消すには位置を表示領域外に設定する
